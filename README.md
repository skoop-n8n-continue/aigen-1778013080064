# Hello World Signage App

A simple "Hello World" application built for the Skoop platform.

## Features
- Data-driven content using `data.json`
- Live preview bindings with `data-bind-*` attributes
- Responsive design
- Themed using Skoop's primary colors

## Structure
- `index.html`: Main entry point
- `data.json`: Application schema and content
- `styles.css`: Visual styling
- `script.js`: Data loading and initialization
- `assets/`: Directory for images and other media
